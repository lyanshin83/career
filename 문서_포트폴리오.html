BACKGROUND · 배경

더에이블랩 6개 쇼핑몰 운영 환경. 화장품 신규 브랜드 닥터미라클 + 자사몰(drmiracle.co.kr) 런칭 TFT 책임. 메타 2.5억 + 포털DA 2.5억 통합 운영 환경에서 신규 브랜드의 1순위 매출 채널을 메타 영상 캠페인으로 결정.

ACTION · 한 일

  • 브랜드 콘셉 설정 + 자사몰 런칭 TFT 리딩
  • 메타 Advantage+ 캠페인 + 머신러닝 영상 최적화
  • 월 광고예산 2-2.5억 운영 / 광고매체 25개 분산 + 영상 1편 중심
  • 영상 콘텐츠 기획 (인서트·후킹·CTA 구조)
  • 자사몰 + 입점몰 통합 — 까탈릭 신세계 명동·하이버·쇼피 입점 진행

RESULT · 성과

런칭 3개월차 매출 월 7.7억 140%
FB 영상 캠페인 달성 목표 100% → 140%
FB 영상 좋아요 500+
댓글 / 공유 200+ / 300+
  • 2020-06 매출 6.4억 / 2020-07 매출 7.7억 (목표 5억 초과)
  • 광고비 효율 = 영상 1편이 다른 25개 영역 5배 효율

INSIGHT · 인사이트

월 5억 예산은 단일 매체 몰빵 ❌ → 영상 1편 + 25개 영역 분산이 공식. 핵심 메시지 1개 일관 + 매체별 KPI 분리. 메타 Advantage+ 자동 타겟팅이 머신러닝 학습 후 효율 폭발.

BACKGROUND · 배경

라이프앤바이오 푸드케어(이유식) 23년 매출 목표 250억 책임. 기존 네이버 검색·DA 광고를 대행사가 운영했으나 월 3,000만 비용 + 효율 낮음. 메타도 대행 수수료 별도. AI 도구 직접 운영 전환으로 비용 절감 + 효율 개선 미션.

ACTION · 한 일

  • 메타 Advantage+ 직접운영 전환 (대행사 제거)
  • 네이버 자동입찰·AI 타겟팅 효율 재정렬 (키워드·쇼핑·브랜드검색)
  • GA4 AI 인사이트 활용 키워드·매체별 ROI 분석
  • 블로그 키워드 상위노출 전략 (영유아 타겟 키워드 60+)
  • 라이브커머스(베라쇼) + 산후조리원 영유아 타겟 DB 마케팅
  • 오메가3 공동구매 2회 진행 (3,000만 매출)

RESULT · 성과

네이버 광고비 월 3,000만 → 월 1,500만 −50%
메타 운영 전환 대행 수수료 → 직접운영 −15%
블로그 1일 방문자 100명 → 2,000명 20×
오메가3 공동구매 3,000만 매출

INSIGHT · 인사이트

AI 자동화의 진짜 가치는 단순한 운영 자동화가 아니라 사람의 판단 시간을 비워주는 데 있다고 봅니다. 메타 Advantage+, 구글 PMax, 네이버 자동입찰을 직접 운영하면 팀원 한 사람이 더 많은 광고주를 책임질 수 있고, 사람의 시간은 광고주 컨설팅과 신규 수주, 전략 의사결정 쪽으로 옮겨놓을 수 있습니다.

  • 4채널 분업화: 네이버스토어 = D2C 1순위·재구매 / 쿠팡 = 신규·로켓 / 자사몰 = LTV·VIP / 홈쇼핑 = 인지·일회성 매출
  • 상시마케팅: 네이버 DA·메타·유튜브 1차 노출 → 검색광고 2차 유입 → 리타게팅 이탈 고객 재유입 (3단 퍼널)
  • SEO·본사 채널: "석고팩" 키워드 네이버 1page 점유 (파워링크·쇼핑·블로그·카페·지식인) + 본사 인스타·카카오 신제품·프로모션 발신
  • 인플루언서: 인스타·유튜브 마이크로~메가 (14.4만, 6.7만 등) 7명+ 협업 — 런칭 홍보 + 콘텐츠 2차 활용
  • 빅셀러 공동구매: 인스타 1회 0.5-1억 이상 판매 빅셀러 (러브지나·반해찌·제이온·재리나·민쓰샵·차메리뉴 등) 협업
  • 라이브커머스: 네이버 쇼핑라이브 (채널 83151) + 알림받기 5천+ 확보 → 라이브 진행

INSIGHT · 운영 철학

멀티 SKU·멀티 채널 운영은 채널별 본질적 강점에 맞춰 SKU·예산을 분배하는 게 핵심. 네이버스토어 = 알림받기·재구매 / 쿠팡 = 신규 트래픽·로켓 전환 / 자사몰 = LTV·VIP 락인 / 홈쇼핑 = 인지·일회성 매출. 4채널 동시 노출 ❌ → 채널×SKU 매트릭스로 우선순위 분해. 상시·SEO·이슈 3-레이어를 같은 시즌 메시지에 묶어 운영하면 같은 광고비로 인지·검색·전환 3중 효율.
